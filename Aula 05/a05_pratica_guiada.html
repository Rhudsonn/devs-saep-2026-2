AULA 05 · Prática Guiada — Construindo a interface principal
5 passos
0 / 5 concluídos
1

Proteger o acesso à tela principal

▸

Garanta que a tela principal só é exibida se houver uma sessão de usuário ativa; caso contrário, redirecione ao login.

se sessao.usuario == null: navegar('login')
Esse é o mesmo tipo de verificação que você vai reaproveitar nas telas de Cadastro e Estoque.
2

Exibir o nome do usuário

▸

Leia o nome guardado na sessão (criada durante o login da Aula 04) e exiba-o na tela principal.

exibir 'Bem-vindo(a), ' + sessao.usuario.nome
Se o nome não aparecer, confira se o login da Aula 04 está realmente salvando o nome na sessão.
3

Criar os acessos de navegação

▸

Adicione dois botões/links: um para 'Cadastro de Produto' e outro para 'Gestão de Estoque', mesmo que levem a telas ainda vazias.

Criar as rotas agora evita retrabalho estrutural nas Aulas 7 e 9 — você só vai precisar preencher o conteúdo.
4

Implementar o logout

▸

Adicione um botão de 'Sair' que limpa a sessão do usuário e retorna à tela de login.

função logout() { sessao.usuario = null; navegar('login'); }
Teste fazendo logout e tentando voltar à tela principal sem logar de novo — ela não deveria abrir.
5

Testar o fluxo completo

▸

Faça login → confira o nome exibido → clique nos dois acessos → faça logout → confirme o retorno ao login.

Esse é o momento de confirmar que Aula 04 e Aula 05 estão realmente integradas.
