AULA 11 · Prática Guiada — Levantando SGBD, linguagem e SO
5 passos
0 / 5 concluídos
1

Verificar a versão do SGBD

▸

Rode o comando de versão do seu SGBD (ex.: mysql --version) e anote o resultado exato.

mysql --version
Se você usa uma ferramenta gráfica (ex.: MySQL Workbench), a versão do SGBD costuma aparecer na tela 'Sobre'.
2

Verificar a versão da linguagem

▸

Rode o comando de versão da linguagem usada na interface (ex.: python --version, node --version) e anote o framework, se houver.

python --version
Não esqueça de anotar a versão do framework também, se você usou um (ex.: Flask 3.0, Django 5.0).
3

Verificar a versão do sistema operacional

▸

Identifique a versão exata do SO da máquina onde o projeto foi desenvolvido.

lsb_release -a # Linux winver # Windows
No macOS, o menu 'Sobre este Mac' mostra a versão do sistema.
4

Montar o documento

▸

Monte a Lista de requisitos de infraestrutura com os 3 itens (SGBD, linguagem, SO), seguindo o modelo do ANEXO III.

1. SGBD: ... 2. Linguagem: ... 3. Sistema Operacional: ...
Mantenha o documento curto e direto — são só 3 itens, mas cada um precisa da versão exata.
5

Exportar como PDF

▸

Exporte o documento final como documentacao.pdf (ou formato acordado com o avaliador).

Confira se o nome do arquivo já está de acordo com o que será exigido na entrega final em .zip.
