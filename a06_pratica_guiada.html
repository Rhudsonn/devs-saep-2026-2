AULA 06 · Prática Guiada — Construindo Create + Read
5 passos
0 / 5 concluídos
1

Criar a tela de Cadastro de Produto

▸

Use a rota/placeholder criada na Aula 05 e monte a estrutura visual: uma tabela vazia e um botão '+ Novo Produto'.

Reaproveite o layout geral da tela principal para manter consistência visual.
2

Implementar a listagem automática

▸

Ao carregar a tela, consulte todos os produtos do saep_db e renderize na tabela, sem exigir nenhum clique do usuário.

SELECT * FROM produto;
Teste abrindo e fechando a tela algumas vezes — os dados devem aparecer sempre, sem clique extra.
3

Construir o formulário de inserção

▸

Crie os campos do formulário: nome, tamanho, peso, estoque atual e estoque mínimo, correspondendo exatamente às colunas da tabela produto.

Confira os tipos de dados definidos na Aula 03 — peso é decimal, estoque é inteiro.
4

Implementar o INSERT

▸

Ao confirmar o formulário, insira o novo produto no banco usando os valores digitados.

INSERT INTO produto (nome, tamanho, peso, estoque_atual, estoque_minimo) VALUES (?, ?, ?, ?, ?);
Use parâmetros (?) em vez de concatenar os valores diretamente na query.
5

Atualizar a listagem após inserir

▸

Depois que o INSERT for concluído com sucesso, recarregue a tabela para que o novo produto apareça imediatamente.

Isso evita que o usuário pense que o cadastro falhou só porque a tabela não mudou visualmente.
